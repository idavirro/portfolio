# Mi Portfolio

Este es mi portfolio hecho para el tp de Laboratorio de Algoritmos y Estructuras de Datos.

La idea es mostrar un poco quien soy, los proyectos que hice y las cosas que estoy aprendiendo de programacion.

## Que tiene

- Una parte de inicio con una foto y botones.
- Mis proyectos como Viper.io, Squid Game y los juegos de Pokemon.
- Una parte sobre mi con las cosas que se usar.
- Preguntas frecuentes que se pueden abrir.
- Un formulario para contactar y descargar mi CV.
- Modo oscuro y modo claro.

## Que use

- HTML para hacer las partes de la pagina.
- CSS para que se vea mas lindo.
- Bootstrap para algunas cosas de la pagina.
- Font Awesome para los iconos.
- Un poco de JavaScript para los botones, el modo claro y los modales.

## Bitacora

Para hacer este proyecto busque bastante como se usaba Bootstrap, porque al principio no sabia mucho de paginas web. Tambien busque como hacer que la navbar se quede arriba, como hacer un modo oscuro y claro y como hacer que las preguntas frecuentes se abran.

Tambien aprendi a poner imagenes de mis proyectos, hacer un favicon y agregar un CV para descargar. Algunas cosas las fui probando, copiando ejemplos y cambiandolas hasta que mas o menos quedaran bien.
